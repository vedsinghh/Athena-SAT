# ATHENA SAT

React + Vite prototype for the ATHENA SAT profile flow and dashboard.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL in your browser.

## Included

- Create local profile
- Open existing profile
- `.athena` profile export/import
- Automatic redirect from profile creation/opening to dashboard
- Dashboard inspired by the approved mockup
- Animated Athena spear score-progress interaction
- Reading / Math cards
- Streak, upcoming practice, recent activity, quick actions
- Responsive layout
- Framer Motion animations
- TailwindCSS styling
